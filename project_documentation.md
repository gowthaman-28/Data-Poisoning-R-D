# Complete Project Documentation

## 1. Project Title
Topological Data Analysis for Defending Deep Learning-Based Network Intrusion Detection Systems Against Data Poisoning Attacks

## 2. Project Type
This is a machine learning and cybersecurity research project with a deep learning classification stage. The main novelty is a data sanitization and poisoning-detection pipeline based on Topological Data Analysis (TDA), while the final intrusion detection model is trained with a deep learning classifier.

## 3. Project Goal
The main goal of this project is to detect and remove poisoned network payload samples before they are used for model training. By doing so, the project aims to improve the robustness of Network Intrusion Detection Systems (NIDS) against data poisoning attacks, especially those that inject backdoor-like payload triggers into the dataset.

## 4. Research Motivation
Traditional ML-based IDS systems often assume the training data is trustworthy. However, in adversarial environments, attackers can inject poisoned samples that manipulate the behavior of the model while still preserving normal aggregate performance. This creates a serious risk in real-world security systems.

This project addresses that challenge by analyzing the underlying structure of payload bytes rather than relying only on classifier behavior. The idea is that poisoned payloads often follow a repeating or structurally distinctive pattern that can be identified through topological signatures.

## 5. Core Idea
The pipeline converts payload bytes into binary 2D representations and then uses Topological Data Analysis to extract persistent topological features. These features are used to identify suspicious clusters of poisoned samples. After detection, the poisoned samples are filtered out, and the remaining clean data is used to train a deep learning-based NIDS.

## 6. Problem Statement
Machine learning-based NIDS models are vulnerable to training-time data poisoning. Attackers can inject malicious traffic samples with crafted payloads that contain triggers designed to manipulate the model. Since these samples may look similar to normal traffic under standard metrics, they can slip through without immediate detection.

This project proposes a data-centric defense strategy that detects and removes such poisoned payloads before training.

## 7. Main Research Questions
- Can poisoned network payloads be identified using their topological structure?
- Do TDA-based features separate poisoned and clean traffic more effectively than raw feature-based methods?
- Can DBSCAN and HDBSCAN detect poisoned clusters reliably?
- Does sanitizing the training data improve the robustness of downstream NIDS models?

## 8. System Overview
The project workflow follows a complete research pipeline:

1. Load and preprocess the UNSW-NB15 dataset
2. Extract packet payload representations
3. Simulate poisoning by injecting malicious trigger patterns
4. Convert payloads into binary grid images
5. Apply topological feature extraction using persistent homology
6. Use DBSCAN and HDBSCAN to cluster samples
7. Identify poisoned and noisy samples
8. Remove suspicious samples from training data
9. Train a deep learning-based intrusion detection model
10. Evaluate final performance and compare clustering methods

Raw packet payloads are extracted and normalized into fixed-length vectors.

Files:
- [src/02_payload_processing.py](src/02_payload_processing.py)
- [data/processed](data/processed)

This stage prepares the payload data for geometric transformation.

### 9.3 Poison Injection
Poisoned samples are generated by replacing selected payloads with crafted trigger patterns.

Files:
- [src/03_poison_generation.py](src/03_poison_generation.py)
- [data/poisoned](data/poisoned)

The dataset contains:
- poisoned dataset,
- poisoned payload matrix,
- poisoned ground-truth labels,
- binarized payloads.

### 9.4 Binarization
The payload is converted into a binary image-like representation to make structural patterns visible.

Files:
- [src/04_binarization.py](src/04_binarization.py)
- [data/poisoned/binarized_payloads.npy](data/poisoned/binarized_payloads.npy)

Each payload is reshaped into a 30x50 binary grid.

### 9.5 Topological Feature Extraction
This is the core analytical stage. Binary payloads are analyzed using filtration methods and persistent homology.

Files:
- [src/05_tda_features.py](src/05_tda_features.py)
- [data/features/tda_features.csv](data/features/tda_features.csv)

Key ideas:
- height filtration in multiple directions,
- radial filtration using different centers,
- computation of persistent homology in H0 and H1,
- use of six amplitude measures,
- generation of a 72-dimensional feature vector per sample.

### 9.6 Clustering and Poison Detection
The extracted topological feature vectors are standardized and clustered using unsupervised learning.

Files:
- [src/06_dbscan.py](src/06_dbscan.py)
- [src/07_hdbscan.py](src/07_hdbscan.py)
- [src/08_evaluation.py](src/08_evaluation.py)

Algorithms used:
- DBSCAN
- HDBSCAN

The clustering stage labels:
- clean clusters,
- poisoned clusters,
- mixed clusters,
- outliers/noise points.

### 9.7 Sanitization
Poisoned or highly suspicious samples are removed before training the intrusion detection classifier.

Files:
- [src/09_sanitize_dataset.py](src/09_sanitize_dataset.py)
- [data/sanitized](data/sanitized)

The cleaned dataset is used for robust training.

### 9.8 Deep Learning Training
The final stage trains a TensorFlow-based classifier for intrusion detection.

File:
- [src/10_deep_learning_nids.py](src/10_deep_learning_nids.py)

This model is trained on sanitized data to classify normal vs attack traffic.

Dataset sources:

The project creates a stratified subset of 25,000 records to ensure balanced class representation while controlling computational cost.

Traffic categories include:

- Generic
- Exploits
- Fuzzers
- DoS
- Reconnaissance
- Analysis
- Backdoor
- Shellcode
- Worms

## 11. Poisoning Strategy
A trigger pattern is injected into a subset of flow payloads. The selected pattern is designed to produce repeated high-structure topological signatures, enabling it to be separated from clean traffic.

The poisoning design uses a checkerboard-style trigger derived from the payload pattern [0xDE, 0x00, 0xBE, 0x00]. This binary trigger creates a distinctive structural pattern in the transformed payload grid.

## 12. Why TDA Is Useful
Traditional byte-level features can miss repeated geometric patterns embedded in malicious payloads. TDA captures shape and connectivity information across multiple scales. This makes it valuable for identifying hidden trigger-based poisoning patterns that may remain visually subtle at the raw data level.

## 13. Results and Findings
The project reports strong evidence that the TDA-based method can detect poisoned traffic effectively.

### 13.1 Quantitative Performance
From the reproduction analysis and the final trained model run on the sanitized dataset:

| Method | Best Configuration | Noise Points | Recall | Precision | F1-score |
|---|---|---:|---:|---:|---:|
| DBSCAN | eps = 1.50, min_samples = 5 | 1,950 | 100% | 39.1% | 56.2% |
| HDBSCAN | min_cluster_size = 200, min_samples = 20 | 249 | 100% | 83.4% | 90.9% |
| Deep Learning NIDS | Sanitized data, 80/20 train-test split | — | 93.90% | 94.15% | 94.03% |

The final TensorFlow classifier achieved an accuracy of 92.38% and ROC-AUC of 98.40% on the test set. Its confusion matrix was:

| Actual \ Predicted | Normal | Attack |
|---|---:|---:|
| Normal | 1525 | 175 |
| Attack | 183 | 2818 |

### 13.2 Key Insights
- Both clustering methods detected all poisoned samples (perfect recall)
- HDBSCAN had substantially better precision than DBSCAN
- HDBSCAN reduced false positives by a large margin
- Persistence-based features remained highly effective for separating poisoned and clean samples
- The clustering method strongly influenced detection quality
- The final deep learning detector trained on sanitized data reached 92.38% accuracy with 94.15% precision and 93.90% recall
- The deep learning model also achieved a strong ROC-AUC of 98.40%, confirming robust detection performance

## 14. Project Outcomes
The project demonstrates that:
- topological signatures can identify poisoning in payload data,
- density-based clustering can isolate suspicious clusters,
- pre-training dataset sanitization is effective,
- deep learning models trained on sanitized data are more defensible in adversarial settings.

## 15. Project Contributions
This project contributes to the field by:
- integrating TDA with intrusion detection data sanitization,
- focusing on pre-training defense rather than post-training correction,
- showing the value of structure-aware anomaly detection,
- evaluating multiple clustering methods under poisoning conditions,
- providing a reproducible pipeline for defense research in NIDS.

## 20. Final Summary
This project presents a full pipeline for defending intrusion detection systems against poisoned training data. The results suggest that TDA-based detection is highly promising for identifying data poisoning patterns before they can compromise the learning model.

In summary, the project is not only a classification task—it is a complete defense framework against adversarial data contamination in network security systems.
